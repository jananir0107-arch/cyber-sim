Control who can access protected resources

What is Access Control?

Access control is a security mechanism that determines who is allowed to access systems, files, applications, or other protected resources.

👤 User Roles

👑 Administrator

Has permission to manage systems and users.

👨‍💻 Employee

Can access resources required for their work.

👤 Guest

Has limited access to protected resources.

🎯 Access Control Operation

Select a user and try to access a protected resource.

👨‍💻 Employee → Security Settings
